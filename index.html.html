How to set up Google Sheets Sync (Free 2-Minute Guide)

  1. Open a new Google Sheet and name it Studio Client Tracker 2026.
  2. Create columns in Row 1: Client Name | Date | Address | Min Revenue | Total Shoots
  3. In your Google Sheet menu, click Extensions ➔ Apps Script.
  4. Replace any code in the editor with this script: 
    function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  
  // Append new shoot entry to sheet
  sheet.appendRow([
    data.name,
    data.sentDate,
    data.address,
    data.minRevenue,
    data.balance,
    new Date()
  ]);
  
  return ContentService.createTextOutput("Success").setMimeType(ContentService.MimeType.TEXT);
}
  5. Click Deploy ➔ New deployment. Select type Web app.
  6. Set "Who has access" to Anyone. Click Deploy and copy the Web App URL into the box above!
